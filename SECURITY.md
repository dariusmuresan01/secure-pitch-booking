# Security policy

## Intentional vulnerabilities

This project contains four vulnerabilities on purpose, for learning. They are
off by default and only active when `VULNERABLE_MODE=1`. They are documented in
[docs/known-vulnerabilities.md](docs/known-vulnerabilities.md) and do not need
to be reported.

## Reporting other issues

If you find a vulnerability that is not listed there, please report it
privately through GitHub's "Report a vulnerability" button in the Security tab
instead of opening a public issue.

## Supported versions

This is a demonstration project and is not maintained for production use.
